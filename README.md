## Zer da?

Web orri bakar bat da, fitxetan antolatua, eta euskaraz dago. Helburua da irakasleek txatbot baten eta agente baten arteko aldea ulertzea, agenteen arriskuak ezagutzea eta gelan modu arduratsuan erabiltzeko irizpideak izatea.

## Edukia

| Fitxa | Zer aurkituko duzu |
|---|---|
| 1. Zer da? | Agentearen definizioa eta txatbotarekiko alderaketa |
| 2. Nola dabil? | Begizta agentikoa (hautematea → planifikatu → ekin → ebaluatu), adibide animatuarekin |
| 3. Osagaiak | Eredua, jarraibideak, tresnak, memoria, plangintza eta baimenak |
| 4. Autonomia | 0tik 4rako autonomia-mailak eta ikastetxerako gomendioa |
| 5. Adibideak | Erabilera-kasuak rolaren arabera iragazita: irakaslea, ikaslea, koordinazioa, tailerra |
| 6. Arriskuak | Datu pertsonalak, haluzinazioak, prompt injekzioa, ekintza itzulezinak... |
| 7. Jardunbide egokiak | Egiaztapen-zerrenda interaktiboa eta prompt-txantiloia |
| 8. Glosategia | Oinarrizko terminoak, bilatzailearekin |
| 9. Probatu zeure burua | 5 galderako autoebaluazio-testa |

## Ezaugarriak

- Orri bakarra (`index.html`): HTML, CSS eta JavaScript barnean, instalaziorik gabe
- Mugikorrean eta ordenagailuan ondo ikusten da
- Gai argia eta iluna
- Ez du datu pertsonalik biltzen

## GitHub Pages-en argitaratzeko

1. Igo `index.html`, `sarrera.jpg`, `README.md` eta `.nojekyll` fitxategiak biltegiaren erroan.
2. Joan **Settings → Pages** atalera.
3. **Source** atalean aukeratu **Deploy from a branch**, adarra `main` eta karpeta `/ (root)`.
4. Gorde eta itxaron minutu batzuk. Orriaren helbidea atal horretan bertan agertuko da.
